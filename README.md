# FLUTTERH₂O
Proyecto para tecnologías en internet - B
emprendimiento-- “FLUTTERH₂O: RIEGO URBANO INTELIGENTE QUE
TRANSFORMA CIUDADES CON CONTROL TOTAL DESDE TU 
APLICACIÓN MÓVIL, SIN FRONTERAS”

FlutterH2O es un pequeño emprendimiento que busca aprovechar la tecnología para mejorar el riego y promover un uso más eficiente del agua. Para apoyar este emprendimiento, se desarrollará un sistema web que contará con una página principal informativa donde las personas podrán conocer el proyecto, los servicios que ofrece y la forma en que funciona el sistema de riego inteligente. También se busca que el sistema permita organizar de mejor manera las consultas, respuestas y archivos relacionados con los clientes, evitando que la información quede dispersa entre mensajes, redes sociales u otros medios. Con este proyecto se pretende facilitar la comunicación con los usuarios, mantener la información más ordenada y, al mismo tiempo, fortalecer la presencia de FlutterH2O en internet para que más personas puedan conocer el emprendimiento y acceder a sus servicios de forma sencilla.
